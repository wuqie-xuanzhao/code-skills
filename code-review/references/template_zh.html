03. 差异工作台
01 // 会话令牌无过期校验
ID: CR-01
文件: auth/session.ts:47
场景: 共享电脑登录 → 管理员撤销令牌 → 用户关闭浏览器 → 下一个人打开 → 令牌仍在 localStorage → 已撤销会话被静默恢复。
当前缺陷
46// 令牌已存储但未追踪过期时间
47localStorage.setItem('session_token', token);
48// 此文件中无过期检查
建议重构
47const session = { token, expires_at: payload.exp * 1000 };
48localStorage.setItem('session', JSON.stringify(session));
49if (Date.now() > session.expires_at) {
50  localStorage.removeItem('session');
51  redirectToLogin();
52}
02 // 并发登录竞态条件
ID: MJ-01
文件: auth/handler.ts:89
原因: 双击"登录" → 两个 POST /login → 都创建会话 → 第二个覆盖 res.session → 孤立会话持续到自然过期。
03 // 冗余 JWT 解码
ID: MN-01
文件: auth/jwt.ts:23
原因: validateToken 每次调用都解码 JWT。在中间件中每个请求都执行。建议用短 TTL 缓存解码后的 payload，或解码一次后向下传递。
