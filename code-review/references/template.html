02 // Concurrent Login Race Condition
ID: MJ-01
File: auth/handler.ts:89
Reason: Double-click "Login" → two POST /login in flight → both create sessions → second overwrites res.session → orphaned first session lingers.
03 // Redundant JWT Decode
ID: MN-01
File: auth/jwt.ts:23
Reason: validateToken decodes JWT on every call. In middleware this runs per-request. Cache decoded payload with short TTL, or decode once and pass downstream.
